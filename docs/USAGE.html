使用模型

启动 Claude Code 或 Codex

ai use claude
ai use codex
ai use claude 51talk
ai use codex 51talk gpt-5.5

不指定 provider 时使用 level: 1；不指定模型时使用 provider 默认 model。

运行规则

  • provider 不可用时按 level 自动降级。
  • Claude Code 使用临时 --settings 注入环境变量，不修改用户 settings。
  • OpenAI 兼容地址用于 Codex 时会使用 /v1，用于 Claude 时会去掉 /v1。
  • 日志只记录 Key 指纹，不记录完整 API Key。

Provider 管理

添加、编辑、删除 
ai provider add
ai provider add 51talk https://example.com sk-xxx
ai provider edit
ai provider edit 51talk
ai provider delete
ai provider delete 51talk
ai provider list
  • mode 可选 ask 或 auto。
  • level 是优先级；如果目标等级已占用，会和对应 provider 交换。
  • model 从已探测模型中选择，不手动输入。
  • 删除 provider 会清理模型缓存；如果 Hermes 正在用它，会切到剩余 provider 中 level 最小的一个。
与 Hermes 的关系
  • Provider 是 AI Gateway 顶层配置，不放在 ai hermes edit 里管理。
  • ai provider add/edit/delete 会自动同步本机 Hermes provider 列表并重启 Hermes gateway。
  • ai provider list 是查看 provider 的唯一列表入口；ai hermes list 只列机器人。

Hermes 机器人

日常操作 
ai hermes
ai hermes add
ai hermes list
ai hermes edit
ai hermes edit robot-name
ai hermes status
ai hermes use robot-name
ai use hermes robot-name
  • 机器人配置保存到 ~/.ai-gateway/hermes.json，只保存 provider 名称，不保存 API Key。
  • ai hermes use 使用独立目录 ~/.ai-gateway/hermes/<机器人名称>/，避免串用全局 Hermes 凭证。
  • ai hermes edit providers 不是有效命令；provider 请用 ai provider edit。
完整迁移、本机 Hermes 导入和 Telegram /model 
ai hermes import-local
ai hermes import-local --overwrite
ai hermes export
ai hermes export robot-name
ai hermes import ./hermes-robot.json
  • export 默认导出所有机器人完整复刻包，包含机器人配置、Telegram 绑定、tasks schedule、关联 provider 配置、API Key 和模型缓存；导出的文件需要私密保存。传入机器人名称时只导出单个机器人。
  • import 导入完整复刻包时会写入关联 provider，并立即同步本机 Hermes 配置、重启 gateway。
  • 旧版不含 provider 的导出文件仍可导入，但目标机器需要已有同名 provider。
  • import-local 扫描 ~/.hermes/config.yaml、channel_directory.json 和 cron/jobs.json。
  • 本机 Hermes provider 会先导入 AI Gateway provider 配置，再统一由 ai provider 管理。
  • 导入后会立即同步 ~/.hermes/config.yaml 并重启 Hermes gateway；不需要单独执行 sync。
  • Telegram /model 只展示 AI Gateway 管理且验证可调用的 provider/model。
  • 同步时会清空 Hermes 原生 provider 凭证入口，避免 MoA、Copilot、openai-codex 等原生 provider 混入列表。

状态和诊断

轻量检查

ai status
ai provider list
ai log
ai log --print
ai context

status 会刷新 provider 健康度和模型缓存，展示 Claude/Codex 各自实际 baseUrl、兼容模型、token 使用量和使用占比。

深度检查

ai doctor
ai doctor --deep

doctor --deep 使用最高优先级可用 provider 验证真实推理链路，可能消耗 token；如果没有 provider 可用，会退回普通 doctor。

会话和报告

Session

ai session
ai session list
ai session clear

session 进入最近 session 选择列表；session clear 清空 AI Gateway 记录。

Report

ai report

选择 session 生成 Markdown 报告，包含 context、真实 token、模型、provider 快照和画像信息。

配置文件

用户可编辑 
~/.ai-gateway/providers.json
~/.ai-gateway/hermes.json

providers.json 保存 provider；hermes.json 保存 Hermes 机器人，不保存 API Key 到机器人配置。

内部状态 
~/.ai-gateway/.ai-cache.json
~/.ai-gateway/usage.json
~/.ai-gateway/sessions.json
~/.ai-gateway/hermes-state.json
~/.ai-gateway/hermes/<机器人名称>/
~/.ai-gateway/reports/
~/.ai-gateway/exports/
~/.ai-gateway/.ai-gateway.log

除非调试问题，否则不要手动修改内部文件。

本机 Hermes 同步目标 
~/.hermes/config.yaml
~/.hermes/.env
~/.hermes/auth.json

AI Gateway 同步时会写入 provider/model 配置、清理原生凭证入口，并重启 Hermes gateway。
